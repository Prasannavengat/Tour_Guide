# Tour Pulse Mobile (Flutter)

This is the Flutter Android app client for the smart tourism backend.

## Features

- Live site crowd status
- Less-crowded recommendations
- Nearby hospitals, police, and essentials
- OpenStreetMap view with nearby markers

## Setup

1. Install Flutter SDK and Android Studio.
2. From this folder, run:

flutter pub get
flutter run

## Backend URL for Android emulator

The app uses:

http://10.0.2.2:4000

If your backend runs on another host/device, change the value in lib/main.dart.
